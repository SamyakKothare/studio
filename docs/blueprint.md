# **App Name**: FACT CHECKER-AI

## Core Features:

- Multi-Modal Input: Accept user input as text, image, or voice and transcribe it to text to prepare for fact-checking.
- Fact Verification Tool: Utilize a Large Language Model (LLM) as a tool to assess the truthfulness of claims by comparing information against multiple sources.
- Source Aggregation: Collect and aggregate information from multiple reliable sources like wikipedia, all government websites of all countries, NASA, ISRO, google search to improve accuracy and confidence in the final verdict.
- Confidence Scoring: Calculate and display a confidence score (0-100%) representing the reliability of the verdict based on source agreement and credibility.
- Verdict Display: Present a clear TRUE/FAKE verdict along with the confidence score and a list of sources used in the verification process.
- Query History: Maintain a history of past queries and verdicts for users to review their previous fact-checking activities.
- Trusted Source Management: Allow users to manage and curate a list of trusted sources to prioritize during the fact-checking process.
- Display "when" and "where": Display "when" and "where" from input if it is true.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and authority.
- Background color: Light gray (#F0F2F5) to provide a clean, neutral backdrop.
- Accent color: Teal (#009688) to highlight important information and calls to action.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern, objective look. Suitable for both headlines and body text.
- Use simple, line-based icons to represent different input methods and fact-checking stages.
- Employ a clean, card-based layout to present verdicts and sources in an organized and easily digestible manner.
- Incorporate subtle animations to provide feedback during input and verification processes.
